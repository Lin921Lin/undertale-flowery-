# Flowey 桌宠 · 一朵会毒舌的 Windows 桌面小花 🌻

> 一款用 Python + PyQt5 实现的桌面宠物。角色取自游戏《Undertale》里的小花 Flowey —— 他会打字机式地和你说话，会学别人说话，会记得你开过他几次、冷落了他多久，也会在你设置了待办之后，在 DDL 前一天一遍遍地来问你「做完了没」。

【待补：桌宠截图 / GIF】

## 灵感与动机

- **为什么做桌宠：** 最初的想法很简单——做一个**陪伴型**的桌面小伙伴。与其放一个只会说「今天也要加油哦」的萌宠，我更想要一个有脾气、有记忆、会反击的「活物」。
- **为什么是 Flowey：** 选 Undertale 的 Flowey 有两个原因。一是他**性格极有特点**：表面礼貌、内里毒舌、偶尔流露真心，层次分明，写起台词来有巨大的发挥空间；二是他**会打破第四面墙**——在原作里他记得每一次存档和重置，把他放到桌面上，这份「他知道自己在你的屏幕里、被你养着」的自觉就变得特别有趣味性。
- **定位：** 不只是观赏，还要真的有用——定闹钟、记待办、每天自动写日记，形成一本**可追溯的记事簿**。

## 功能特性

### 🗨️ 对话系统
- 打字机气泡：台词逐字出现，逐字配音效（blip）
- 台词库由 `lines.json` 驱动（schema v2）：按事件触发（双击、拖拽、发呆、被冷落、开关机、静音……），每种事件有独立的语气配额与冷却时间
- 九档语气系统：`sweet / venom / meta / manic / mimic / mask / crack / plead / tender`，从礼貌南方腔到破防哀求各有严格的出现条件
- `persona.md` 作为「人格约束层」与台词库分离：一个管**怎么说话**，一个管**说什么**

### ⏰ 提醒 · 待办 · 日记（记事簿三件套）
- **定时提醒**：倒计时 / 具体时间两种模式；支持直接粘贴整句「10分钟后提醒我喝水」，自动解析成 (10, 喝水)；到点先响铃，再弹出带头像的大字提醒面板；最多同时挂 8 条，排队依次响
- **待办事项（DDL）**：填内容 + 截止时间，到期前 1 小时 / 10 分钟各来问一次「完成没」——答「做完了」或「还没」他会给你不同的反应
- **自动日记**：`flowey_diary.txt`，当天定过的每一条提醒 / 待办（含已响、已取消、已完成）自动同步成流水账，末尾附最多 5 条「Flowey 批注」，用系统记事本直接打开，形成可追溯的记事簿

### 🎭 拟人行为
- **变脸模仿**：随机触发「学人说话」，模仿 Sans / Papyrus / Toriel / Asgore 时会换上对应的脸并播放对应角色语音；模仿重置 / 存档话题时切 Frisk 脸
- **进程监控**：后台扫描进程，检测到 Steam / 微信 / 浏览器 / 视频 / IDE 新出现时吐槽一句（15 分钟冷却）
- **被冷落会游荡**：长时间不理他，他会钻地 → 在屏幕各处冒头张望 → 最后钻到你鼠标旁边骚扰你
- **会反抗**：被反复戳 / 拽会直接钻地跑路；盆栽形态下右键菜单仍然可用
- **记得一切**：开关次数、静音、忽略时长都有状态持久化，重启也不会失忆

### 🎨 表现层
- 无边框 + 完全透明 + 始终置顶，不占任务栏
- 全套素材带 2 画布像素黑描边（白底页面也能看清剪影），脚本批量处理贴图透明化
- 出场 BGM 循环 + 独立音效系统（逐字音 / 邪笑 / 变脸语音），可整体开关且记住偏好

## 开发历程与踩坑

### 教训一：别想一口吃成胖子
最初版本的记事簿想**一次性把功能全做齐**，加上 AI 辅助一起搞，结果写了 7 个小时、报错堆成山，最后什么都跑不起来。
重构思路变成：**从最小可运行版本开始**——先让一朵花出现在屏幕上，再一个功能一个功能往上叠（对话 → 提醒 → 待办 → 日记 → 行为系统）。每一步都能跑、能演示、能回退。

### 教训二：动画和贴图是重灾区
- 早期**每次设置钻地动画电脑都会卡壳**，一度只能绕开动画帧
- 修复「钻地卡住」的 bug：QMovie 播放完成的信号丢失（例如播到一半改尺寸导致动画被重建）后，钻地动画会永远停在土里、出场也永远不定格。解决办法是给动画完成路径加兜底：信号丢了也能靠超时 + 状态机恢复，不再死等一个永远不会来的回调

### 经验
- AI 工具很适合加速「写代码」，但**架构取舍、bug 定位、验收标准必须自己掌握**，否则报错时会同时失去代码和时间的掌控权
- 小步迭代 + 每步可验证，比大而全的一次性设计靠谱得多

## 运行方式

```bash
pip install PyQt5 psutil
python flowey_pet.py
```

Windows 下也可以直接双击 `start_pet.bat`（调试用 `start_pet_debug.bat`）。

## LLM 对话调试台（独立，未接入桌宠）

在把大模型接进桌宠之前，先用命令行验证「人设是否立得住」。脚本零第三方依赖（只用 `urllib`），直接跑 DeepSeek：

```bash
python flowey_chat_debug.py --check                    # 密钥连通性自检
python flowey_chat_debug.py                            # 进入交互对话
python flowey_chat_debug.py -m "我回来了，你今天干嘛了"   # 单句对话
python flowey_chat_debug.py --event double_click       # 模拟桌宠事件，生成即兴台词
```

Windows 下双击 `start_chat_debug.bat` 即可进入交互模式。

**人设来源**：`persona.md`（人格约束层）+ `lines.json` 的 `speechNotes` / `toneEnum` / `forbiddenWords` / 台词抽样，全部自动注入 system prompt，不需要手写第二份人设。

**本地护栏**：模型返回的台词会先过一遍关键词/句式黑名单（黏着式表达、AI 服务型承诺、求关注、双向情感暗示、硬性禁词），命中就让模型带着原因重写一次，并在终端标出 `↺ 撞护栏已重写`。这套护栏之后可直接复用到桌宠里做兜底。

**密钥管理**：密钥放在 `secrets.local.json`（已在 `.gitignore` 中忽略，不会进 Git），同目录下的 `secrets.template.json` 是空模板，可以安全提交。也支持用环境变量 `DEEPSEEK_API_KEY` 覆盖。

## 目录结构

```
├── flowey_pet.py              # 主程序（窗口/对话/提醒/待办/日记/行为系统）
├── lines.json                 # 台词库（事件 → 语气 → 台词，schema v2）
├── persona.md                 # 人格约束层（说话规则，与台词库分离）
├── flowey_diary.txt           # 自动生成的日记（可追溯记事簿）
├── flowey_assets/             # 贴图 / 动画 / 音效素材
├── make_transparent_assets.py # 贴图透明化批处理脚本
├── make_sfx.py                # 音效生成/处理脚本
├── start_pet.bat              # 一键启动
├── flowey_chat_debug.py       # LLM 对话调试台（独立，不进主程序）
├── start_chat_debug.bat       # 调试台一键启动
├── secrets.local.json         # 【私密】本地密钥，已 gitignore
├── secrets.template.json      # 密钥模板（空值，可提交）
└── chat_logs/                 # 对话调试日志（自动生成，已 gitignore）
```
